Belle Binette

        

          Belle Binette is a lightweight avatar generator, inspired by the illustration books from the 60's ith a modern
          twist. The avatar is generated with a simple combination of .css classes and .svg assets. This project is
          handmade and no shitty AI is involved. Right now this page is a non published work in progress made public to
          test. This project aimed to be open source soon, stay tuned!
